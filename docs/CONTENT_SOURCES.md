## 6. 検証ワークフロー（次回への参考）

1. Sefaria.org でキーワード検索（英語訳が見つけやすい）
2. 元のヘブライ語に近い英訳を確認
3. 該当箇所の前後文脈を読み、本当にその趣旨か判断
4. **特に「タルムード」「伝統的格言」とした項目は、他宗教文献（仏教、道家、新約聖書）由来でないか必ず確認**
5. 確信が持てたら (趣旨) を除去
6. 確信が持てなければ (趣旨) を残し、本ログに探索ヒントを記録

### 第2巡で確認できた重要な事実

- **#38（木と葦）** は当初 Aesop 寓話の混入を疑ったが、**Talmud Taanit 20b** にラビ・シメオン・ベン・エルアザル名で同型の格言が存在することを確認。両者は独立平行発生またはユダヤ→ギリシャの流入と推定される。**問題なくユダヤ文献として扱える**。
- **#49（砂の上に家）** はマタイ福音書 7:24-27 由来を疑ったが、**Avot d'Rabbi Natan 24** にエリシャ・ベン・アヴーヤ名で「行いなき学びは石の上の泥煉瓦」という並行ミドラーシュが存在。教えのテキストをこの並行版に書き換えて、ユダヤ起源を明確化。
