# アプリの短い説明（80字以内）3案

> Play Console: 「ストアの掲載情報 → 短い説明」に貼り付け。
> 検索結果やおすすめ枠で最初に目に触れる文。**最初の30字が勝負**。

---

## A案: 機能の幅広さ訴求（49字）

```
日本株・米国株・為替・暗号資産の主要指標と、毎日1つのタルムードの教え。古代の知恵で投資を見つめ直す。
```

**特徴**: 「何ができるか」を明示。検索流入に強い（株、為替、暗号資産のキーワード網羅）。
**向いている層**: 機能を見て決める実用派の投資家。

---

## B案: ユニーク要素訴求（45字）

```
2000年の知恵を、今日の投資判断に。19の市場指標と100のタルムードの教えが、賢者の習慣を支える。
```

**特徴**: 「2000年」と「19/100」という数字でユニーク性を強調。
**向いている層**: 知的好奇心が強い層、習慣化志向の人。

---

## C案: 心理面・共感訴求（44字）

```
相場に振り回されない自分へ。タルムードの教えと市場指標を毎朝1分で。賢者の習慣を育てる金融アプリ。
```

**特徴**: 「相場に振り回される」という痛みに共感し、解決を提示。
**向いている層**: 投資の感情コントロールに悩む層、ストアレビューで自己投影しやすい層。

---

## 推奨

**C案（共感型）** を第一候補に推奨します。理由:

1. **痛みポイント（相場に振り回される）** が具体的で刺さる
2. **「毎朝1分」** という小さなアクションでハードルが低い
3. **「賢者の習慣」** がアプリ名「タルムードに学ぶ」と韻を踏み、ブランド一貫性が高い
4. 検索キーワード「タルムード」「金融」「市場」をすべて含む

A案は機能訴求では強いが、競合（楽天証券アプリ等）と差別化しにくい。
B案は「2000年」が刺さる人とスルーする人で分かれる。
