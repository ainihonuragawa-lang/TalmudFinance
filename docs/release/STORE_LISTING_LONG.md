## 構成解説

| セクション | 字数目安 | 役割 |
|---|---|---|
| キャッチ + サブ | 60字 | 最初の3秒で「何の話か」を伝える |
| このアプリでできること | 130字 | スキャン読みでも把握できる箇条書き |
| こんな方におすすめ | 130字 | 自分のことだ、と思わせる |
| 主な機能（4ブロック）| 600字 | 詳しく知りたい人向けの深掘り |
| プライバシー配慮 | 200字 | 信頼性アピール、申請通過にも寄与 |
| 開発者メッセージ | 400字 | 共感を生み、レビュー★5への動線 |
| キーワード羅列 | 130字 | ASO用、自然な範囲で網羅 |

合計: 約1,900字 / 4000字制限の48%

## ASO（アプリストア最適化）配慮

組み込まれている検索キーワード:
- **主軸**: タルムード、賢者、金融、投資
- **市場系**: 日経平均、S&P 500、NASDAQ、為替、USD/JPY、ビットコイン
- **行動系**: 毎日、朝、習慣、判断、ノイズ
- **層別**: 投資初心者、長期投資、分散投資、複利

**キーワード詰め込みの不自然さは回避**しつつ、文中で3〜5回自然に重複させています。

## Play Console での貼り付け方

1. Play Console → アプリを選択
2. 左メニュー: **「ストアの表示 → メインのストア掲載情報」**
3. **「短い説明」** に上記 STORE_LISTING_SHORT.md の C案を貼り付け
4. **「詳細な説明」** に上記 STORE_LISTING_LONG.md の本文（コードブロック内）を貼り付け
5. **保存** → 「変更を確認」を確認後、リリースタイミングで反映
