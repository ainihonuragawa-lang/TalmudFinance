# Play Store スクリーンショット撮影ガイド

> 実機（Google Pixel 7）でアプリのスクリーンショットを撮り、Play Store の申請素材を揃える。
> 所要時間 **約20分**。

---

## 0. 前提知識

### Play Store の要件（電話用スクリーンショット）

| 項目 | 仕様 |
|---|---|
| **最小枚数** | 2枚 |
| **推奨枚数** | **8枚**（最大）|
| **画像サイズ** | 短辺 320px〜長辺 3840px、アスペクト比 16:9〜9:16 |
| **Pixel 7 ネイティブ解像度** | 1080×2400 px → そのまま使える ✅ |
| **ファイル形式** | JPEG または 24bit PNG |
| **ファイルサイズ上限** | 8MB/枚 |

→ Pixel 7 の標準スクショ機能で撮ったものを **無加工で提出可能**。

---

## 1. Pixel 7 でのスクリーンショット撮影方法

### 方法A: ボタン同時押し（推奨・最速）

**電源ボタン** + **音量↓ボタン** を同時に短く押す。

シャッター音が鳴って、左下にプレビューが出る。

### 方法B: 最近のアプリ画面から

1. ホームから下から上にスワイプして止める（最近のアプリ表示）
2. アプリのサムネイル下部の **「スクリーンショット」** をタップ

---

## 2. 撮るべき8枚

### 構成方針

**最初の2枚で「このアプリは何か」が伝わるように**するのが Play Store コンバージョンの鉄則です。「タルムードの教え」というユニーク要素と「金融データ」の両方を最初の2枚で見せます。

### 8枚のリスト

| # | 画面 | 操作前の準備 | 撮影内容 |
|---|---|---|---|
| **1** | ホーム（今日タブ）| アプリ起動直後、画面トップが見える状態 | タルムードの教えカード全体が見える状態 |
| **2** | ホーム（今日タブ）| 画面を少し下にスクロール | 主要指標サマリー（日経・S&P500 等）が中央に見える状態 |
| **3** | マーケット → 日本株 | マーケットタブをタップ → 日本株タブを選択 | 日本株5銘柄が一覧表示 |
| **4** | マーケット → 米国株 | 米国株タブを選択 | 米国株6銘柄が一覧表示 |
| **5** | マーケット → 為替 | 為替タブを選択 | FX 4ペアが一覧表示 |
| **6** | マーケット → 暗号資産 | 暗号資産タブを選択 | BTC/ETH 等が一覧表示 |
| **7** | 教え一覧 | 教え一覧タブをタップ、画面トップで停止 | #1〜#3 あたりの教えカードが見える |
| **8** | 教え一覧 | 画面中程までスクロール | #40 付近（テーマが多様な範囲）が見える |

### 撮影前のセットアップ

- ✅ **機内モード OFF / Wi-Fi 接続済み**（市場データが正常表示されていること）
- ✅ **アプリのデータ取得完了済み**（赤いエラーバーが出ていない）
- ✅ **時刻**: ステータスバーの時計を綺麗な数字に揃えたいなら「9:41」「11:30」等のキリ番タイミングを狙う（任意）
- ✅ **バッテリー**: 80%以上ある状態だと電池アイコンが綺麗
- ✅ **通知バッジ**: 余計な通知が出ていないことを確認

## 3. PC への転送方法

撮ったスクリーンショットを PC に持ってくる3つの方法:

### 方法A: USB ケーブル経由（最速）

1. Pixel 7 を PC に USB ケーブルで接続
2. Pixel 7 で USB 通知 →「**ファイル転送 (MTP)**」を選択
3. PC のエクスプローラーで `Pixel 7 → Internal shared storage → Pictures → Screenshots`
4. スクショ画像を PC にコピー

### 方法B: Google フォト経由（同期済みなら最も簡単）

1. Pixel 7 で Google フォトを開く
2. 該当のスクショを **共有** → **アルバム** または **リンク作成**
3. PC のブラウザで photos.google.com にログインしてダウンロード

### 方法C: Google ドライブ経由

1. Pixel 7 のフォトアプリでスクショを選択
2. **共有** → Google ドライブ にアップロード
3. PC で drive.google.com からダウンロード

## 5. 整理後の確認

### サイズと枚数のチェック

エクスプローラーで各ファイルを右クリック → プロパティ → 詳細タブで:

- 幅: 1080 px ✅
- 高さ: 2400 px ✅
- ファイル形式: PNG ✅
- ファイルサイズ: 1〜2MB 程度（8MB 以下）✅

### 内容の最終チェック（送信前に必ず）

- [ ] 個人情報が映り込んでいない（通知の内容、連絡先など）
- [ ] バッテリー残量が極端に低くない（赤くないこと）
- [ ] 機内モードアイコンが出ていない
- [ ] アプリ内のデータが「N/A」「エラー」になっていない
- [ ] 8枚すべての内容が異なる（全部似た画面ではない）

## 6. 任意：プロフェッショナル感を上げる工夫

時間に余裕があるなら、以下の加工で見栄えが上がります（必須ではない）:

### A. ステータスバーをクリーンアップ

Pixel 7 の **「開発者向けオプション → デモモード」** を有効化すると:
- 時計を「12:00」固定
- バッテリー 100%
- Wi-Fi 4本
- 通知アイコンをクリア

の状態で撮影できます。これで「広告写真っぽい」画面になる。

設定方法（ご興味あれば）:
1. 設定 → 開発者向けオプション
2. 「**システム UI チューナー**」または「**デモモード**」を探す
3. Pixel 純正だと存在しない場合あり。ADB 経由で有効化することもできる

### B. 枠付きの「デバイスモックアップ」を作成

Play Store の他のアプリのように、Pixel 7 の枠で囲んだスクリーンショットにすると見栄えが上がります。
無料ツール:
- [DeviceFrames.com](https://deviceframes.com/) — ブラウザでスクショをアップロード → Pixel 7 枠付きでダウンロード
- [MockUPhone](https://mockuphone.com/) — 同様のサービス

ただしこれは Play Store 必須ではなく、**素のスクショでも申請通ります**。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| スクショが暗すぎる / 明るすぎる | 端末の明るさを中央付近に調整してから撮り直し |
| ステータスバーが邪魔 | 上記の §6.A デモモードで隠す、または画像編集で切り抜き |
| 1枚だけ解像度が違う | Pixel 7 で撮ったか確認、別端末で撮った場合は再撮影 |
| Play Console で「サイズが不適切」と弾かれる | 短辺 320 以上、長辺 3840 以下、比率 9:16〜16:9 を確認 |
